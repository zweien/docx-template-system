# 动态表格块

动态表格用于生成可变行的明细表（如材料清单、费用明细、人员列表等）。

## 基本语法

在 Word 表格中用 `{{#blockName}}` 和 `{{/blockName}}` 标记循环区域：

```
┌──────────┬──────────────┬──────────┐
│ 序号     │ 名称         │ 数量     │
├──────────┼──────────────┼──────────┤
│ {{#材料}} │              │          │  ← 起始标记行
├──────────┼──────────────┼──────────┤
│ {{序号}}  │ {{名称}}     │ {{数量}} │  ← 模板行（会被复制）
├──────────┼──────────────┼──────────┤
│ {{/材料}} │              │          │  ← 结束标记行
└──────────┴──────────────┴──────────┘
```

## 渲染效果

假设表单数据为：

```json
{
  "材料": [
    { "序号": "1", "名称": "钢材", "数量": "100吨" },
    { "序号": "2", "名称": "水泥", "数量": "500吨" },
    { "序号": "3", "名称": "砂石", "数量": "300方" }
  ]
}
```

生成结果：

```
┌──────────┬──────────────┬──────────┐
│ 序号     │ 名称         │ 数量     │
├──────────┼──────────────┼──────────┤
│ 1        │ 钢材         │ 100吨    │
├──────────┼──────────────┼──────────┤
│ 2        │ 水泥         │ 500吨    │
├──────────┼──────────────┼──────────┤
│ 3        │ 砂石         │ 300方    │
└──────────┴──────────────┴──────────┘
```

## 规则

- **块名** 支持中文、英文和下划线（如 `材料`、`items`、`费用明细`）
- 每个块名只能出现一对 `{{#name}}` / `{{/name}}` 标记
- 起始标记和结束标记必须在**同一个 Word 表格**中
- 起始标记行和结束标记行之间的 `{{ key }}` 会被识别为列定义
- 列定义的 key 同样支持中文

## 多个表格块

同一个模板可以包含多个独立的表格块，只要块名不同即可：

```
{{#材料}} ... {{/材料}}
{{#设备}} ... {{/设备}}
```

每个表格块独立循环，互不影响。

## 表单中的表现

在动态表单中，动态表格块会显示为可编辑的表格：

- 可添加/删除行
- 每行的列与模板中定义的 key 对应
- 支持批量粘贴数据
