# 文档收集

文档收集模块用于创建文件收集任务，指定收集人名单和截止时间，收集人上传文件后系统自动管理。

## 创建收集任务

1. 进入 **文档收集** 页面
2. 点击 **新建任务**
3. 填写任务信息：
   - 任务名称
   - 截止时间
   - 收集人名单（可从用户列表选择，支持全选）
   - 文件重命名规则
4. 发布任务

## 文件提交

收集人收到任务后：

1. 进入任务详情页
2. 上传文件
3. 系统按配置的规则自动重命名
4. 提交成功后等待管理员查看

## 版本追踪

- 支持多次提交，每次提交保留完整版本历史
- 管理员可查看任意历史版本
- 收集人可在截止时间前替换已提交的文件

## 批量下载

管理员可一键打包下载所有提交的文件：

- 按收集人分目录组织
- ZIP 格式打包
- 包含提交时间和版本信息

## 任务管理

| 操作 | 说明 |
|------|------|
| 查看进度 | 实时查看每位收集人的提交状态 |
| 催交提醒 | 向未提交的收集人发送提醒 |
| 延长截止时间 | 修改任务的截止时间 |
| 关闭任务 | 不再接受新的提交 |
