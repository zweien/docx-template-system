# 模板管理

模板是整个系统的核心。系统支持两种模板类型：

- **填表生成型** — 上传带 `{{ placeholder }}` 标记的 Word 模板，系统自动解析占位符，配置后通过动态表单填写数据生成文档。
- **文件下载型** — 上传一套文件（复杂表格、材料包等），打包成 zip 供团队直接下载，适合无法在线填写的场景。

## 模板生命周期

模板有以下几个状态：

| 状态 | 说明 |
|------|------|
| **草稿** | 初始上传后的状态，可编辑配置 |
| **已发布** | 发布后可被用户使用生成文档 |
| **已归档** | 归档后不再显示在模板列表中 |

## 创建模板

1. 进入 **模板管理** 页面
2. 点击 **上传模板** 按钮，选择模板类型：
   - **填表生成型** — 进入上传向导，选择 `.docx` 文件，系统自动解析占位符
   - **文件下载型** — 进入文件上传表单，可多选上传任意格式文件（docx / xlsx / pdf / zip / 图片等）

### 填表生成型

选择 `.docx` 格式的 Word 文件后，系统自动解析文件中的占位符，随后进入三步向导：上传文件 → 配置占位符 → 确认发布。

### 文件下载型

适合包含复杂表格、或本身是一套文件（无需在线填写生成）的场景：

1. 填写模板名称、描述、分类、标签
2. 拖拽或点击上传多个文件（支持任意格式）
3. 系统自动打包为 zip
4. 详情页可查看文件清单、单独下载某个文件或一键下载全部

## 配置占位符（仅填表生成型）

上传填表生成型模板后，系统会自动识别出所有 `{{ key }}` 标记。你可以在配置页面中：

- **编辑标签** — 为每个占位符设置显示名称
- **设置类型** — 选择文本、多行文本或明细表
- **设置顺序** — 拖拽调整占位符在表单中的显示顺序
- **必填设置** — 标记某些字段为必填

> 文件下载型模板不涉及占位符，编辑时直接跳过此步骤。

## 文档在线预览

模板、历史版本以及生成后的文档均支持在线预览，无需下载即可查看内容：

- 模板详情页点击「预览模板」
- 版本历史中预览任意历史版本
- 文档生成后在记录详情页点击「预览文档」

预览基于浏览器端渲染，支持 docx 等格式的直接查看。

## 截图管理

每个模板都可上传一张截图，作为模板列表和详情页的预览图。管理员可在详情页上传或删除截图。

## 版本历史

每次发布模板都会生成一个版本快照，你可以随时查看历史版本、预览或下载。两种模板类型都支持版本历史。

## 批量操作

支持批量选择模板进行：
- 批量发布/归档
- 批量导出
- 批量删除
