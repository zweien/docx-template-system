# 模板管理

模板是整个系统的核心。用户上传带有 `{{ placeholder }}` 标记的 Word 模板文件，系统自动解析占位符，配置后即可用于文档生成。

## 模板生命周期

模板有以下几个状态：

| 状态 | 说明 |
|------|------|
| **草稿** | 初始上传后的状态，可编辑配置 |
| **已发布** | 发布后可被用户使用生成文档 |
| **已归档** | 归档后不再显示在模板列表中 |

## 上传模板

1. 进入 **模板管理** 页面
2. 点击 **上传模板** 按钮
3. 选择 `.docx` 格式的 Word 文件
4. 系统自动解析文件中的占位符

## 配置占位符

上传模板后，系统会自动识别出所有 `{{ key }}` 标记。你可以在配置页面中：

- **编辑标签** — 为每个占位符设置显示名称
- **设置类型** — 选择文本、多行文本或明细表
- **设置顺序** — 拖拽调整占位符在表单中的显示顺序
- **必填设置** — 标记某些字段为必填

## 版本历史

每次更新模板文件都会保留历史版本，你可以随时查看和回退到之前的版本。

## 批量操作

支持批量选择模板进行：
- 批量发布/归档
- 批量导出
- 批量删除
