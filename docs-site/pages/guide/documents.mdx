# 文档生成

基于已配置的模板，通过动态表单填写数据，一键生成 Word 文档。

## 生成单个文档

1. 选择一个已发布的模板
2. 系统自动根据模板占位符生成动态表单
3. 填写表单数据
4. 点击 **生成文档** 按钮
5. 下载生成的 `.docx` 文件

### 动态表单

表单类型取决于模板中的占位符配置：

| 占位符类型 | 表单控件 |
|-----------|----------|
| 简单文本 | 单行输入框 |
| 多行文本 | 多行文本域 |
| 明细表（动态表格块） | 可编辑表格 |

### AI 填充助手

在表单填写页面，你可以使用 AI 填充助手来智能推荐字段值。点击表单旁的 AI 图标，输入描述即可让 AI 帮你填写表单。

## 批量生成

1. 进入模板详情页
2. 点击 **批量生成** 按钮
3. 上传 Excel 文件（包含与占位符对应的列）
4. 系统自动映射字段
5. 确认映射关系后，一键批量生成

Excel 文件中每行对应一个文档，列名应与模板占位符名称匹配。

## 草稿系统

表单数据会自动保存为草稿，你可以：

- 随时中断填写
- 下次打开时恢复到上次的填写状态
- 管理多个草稿

## 文档记录

所有生成的文档都会保留记录，包括：

- 生成时间
- 操作人
- 使用的模板和版本
- 填写的数据
- 生成的文件下载链接
