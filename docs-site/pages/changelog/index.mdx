# 更新日志

本页记录 DOCX Template System 的主要版本更新。完整日志请查看 [CHANGELOG.md](https://github.com/zweien/docx-template-system/blob/master/CHANGELOG.md)。

## v0.10.1 (2026-05-07)

### Features
- 文档收集任务支持全选/反选分配人
- 预算报告从 Excel 摘要页提取章节描述
- 桌面应用新增图片宽度、标题层级全局配置
- 桌面应用模板管理页支持下载示例模板
- report-engine 使用命名样式渲染表格单元格

### Bug Fixes
- 修复桌面应用 TypeScript 错误
- report-engine 修复合并拆分 XML run 和 OMML 命名空间问题

## v0.10.0 (2026-05-05)

### Features
- 新增命令面板（Ctrl+K），替代全局搜索
- 模板和记录支持批量操作（选择、删除、导出）
- 搜索扩展到多个数据源
- 桌面应用新增 Excel 合并功能
- 桌面应用新增模板导入验证
- 全局导航键盘快捷键

## v0.9.0 (2026-05-03)

### Features
- 新增预算报告向导页面（三步流程）
- 报告编辑器 AI 章节自动填充（流式预览）
- 报告编辑器支持 PROMPT 注解
- 桌面应用新增完整的文件验证系统
- 编辑器气泡菜单新增固定选区按钮
- 导出 API 修复 DOCX 损坏问题（OMML 命名空间）

## v0.8.0 (2026-05-03)

### Features
- 新增"关于"页面和侧边栏底部导航
- 桌面应用完整实现：4 步向导、配置管理、日志面板
- 报告编辑器 AI 动作管理（全局 + 个人）
- 报告编辑器 AI 对话侧边栏
- 报告编辑器协作功能完善

## v0.7.0 (2026-04-27)

### Features
- 报告撰写模块上线
- BlockNote 富文本编辑器集成
- Yjs + y-websocket 实时协作
- report-engine Python 服务集成
