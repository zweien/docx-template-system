# 图片

在模板和报告渲染中支持插入图片。

## 报告中的图片

在报告撰写编辑器中，可以直接上传和插入图片。导出 DOCX 时，图片会被嵌入到文档中。

## report-engine 图片块

在 payload 中使用图片块：

```json
{
  "type": "image",
  "src": "base64编码的图片数据或URL",
  "alt": "图片描述",
  "caption": "图1 示例图片",
  "width": "80%"
}
```

### 图片来源

支持以下图片来源：

| 来源 | 格式 |
|------|------|
| Base64 | `data:image/png;base64,iVBOR...` |
| URL | `https://example.com/image.png` |
| 本地路径 | `/path/to/image.png` |

### 图片宽度

- 支持百分比：`"80%"`
- 支持厘米：使用 `Cm()` 函数

## 图片标题和编号

渲染引擎支持自动图片编号：

- 使用 SEQ 域代码实现自动编号
- 标题样式为"图片标题"
- 可通过 `auto_number_captions` 配置开关

## 图片段落

图片块会生成包含图片和标题的段落，使用"图片段落"样式。

## 图例

支持图例块（legend），用于展示图表说明：

```json
{
  "type": "legend",
  "text": "图例说明文字"
}
```
