# 自动化引擎

自动化引擎提供触发器驱动的自动化工作流，在数据变化时自动执行预设动作。

## 触发器

支持以下触发类型：

| 触发器 | 说明 |
|--------|------|
| 记录创建 | 当新记录被创建时触发 |
| 记录更新 | 当记录被更新时触发 |
| 记录删除 | 当记录被删除时触发 |
| 字段变更 | 当指定字段的值发生变化时触发 |
| 定时触发 | 按设定的时间计划触发 |
| 手动触发 | 用户手动点击按钮触发 |

## 条件分支

每个自动化可配置条件节点：

- 支持单条件节点下的 `AND/OR` 组合判断
- 根据判断结果走 `Then/Else` 分支
- 可嵌套多个条件判断

## 动作执行

当前支持的动作类型：

| 动作 | 说明 |
|------|------|
| 更新字段 | 更新当前记录的指定字段 |
| 创建记录 | 在指定数据表中创建新记录 |
| 更新关联记录 | 更新与当前记录关联的其他记录 |
| 调用 Webhook | 向外部 URL 发送 HTTP 请求 |
| 添加评论 | 给当前记录添加评论 |
| 发送模板邮件 | 基于 SMTP 配置发送邮件 |

## 运行日志

- 为每次自动化执行落库 `run/step` 记录
- 保留执行状态、耗时、错误信息
- 可在日志页面查看历史执行记录

## 告警通知

- 运行失败时向创建者推送站内通知
- 通知包含错误详情和上下文信息

## 画布编辑器

提供结构化的自动化画布编辑器：

- 触发器 → 条件 → 分支动作的清晰结构
- 避免自由拖拽带来的拓扑失控
- 直观的流程可视化
