# 预算报告

预算报告模块通过三步向导，将 Excel 数据快速转换为格式化的 Word 报告。

## 三步向导

### 第一步：选择模板与配置

1. 选择已上传的预算报告模板（`.docx` 格式）
2. 上传或选择已有的配置方案（JSON 格式）
3. 配置内容包括：
   - 工作表映射
   - 列名映射
   - 字段规则
   - 输出格式

### 第二步：上传 Excel 并校验

1. 上传 Excel 文件（`.xlsx` 格式）
2. 系统实时校验：
   - 工作表是否存在
   - 列名是否匹配
   - 数据格式是否正确
   - 填写率是否达标
3. 校验结果以可视化方式展示，标明问题所在

### 第三步：预览并生成

1. 预览生成效果
2. 确认无误后生成 DOCX 文件
3. 下载生成的报告

## 配置管理

配置方案定义了 Excel 数据与 Word 模板之间的映射关系：

- **自定义校验规则** — 设置数据格式要求和校验逻辑
- **字段映射** — 定义 Excel 列名与模板占位符的对应关系
- **JSON 导入导出** — 配置方案可导出为 JSON 文件，方便复用和分享

## 桌面应用

预算报告功能也支持在桌面应用中离线使用。详见 [桌面应用](/guide/desktop) 章节。
