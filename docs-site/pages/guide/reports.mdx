# 报告撰写

报告撰写模块提供从模板创建、在线编辑到导出 DOCX 的完整工作流，支持 AI 辅助写作和多人实时协作。

## 报告模板

### 创建模板

1. 上传 `.docx` 文件作为报告模板
2. 系统自动解析章节结构和上下文变量
3. 可为每个章节配置 AI 写作提示词
4. 发布后供团队成员使用

### 模板结构

报告模板支持以下占位符：

- `{{章节标题}}` — 章节内容占位，由富文本编辑器填充
- `{{简单字段}}` — 普通文本替换
- `{{#blockName}}...{{/blockName}}` — 动态表格块
- `{{p key_SUBDOC}}` — 子文档引用（支持嵌套富文本）

## 富文本编辑器

基于 BlockNote 编辑器，支持丰富的内容类型：

| 类型 | 说明 |
|------|------|
| 段落 | 普通文本段落 |
| 标题 | H1-H5 多级标题 |
| 列表 | 有序列表、无序列表 |
| 表格 | 可编辑表格 |
| 公式 | LaTeX 数学公式 |
| Mermaid 图表 | 流程图、序列图等 |
| 图片 | 上传图片插入 |
| 附件 | 上传附件文件 |

## AI 智能写作

### 章节级生成

- 点击章节旁的 AI 按钮，输入写作要求
- AI 流式输出内容，实时预览
- 支持编辑提示词后再生成

### AI 对话侧边栏

- 在编辑器旁打开 AI 对话
- 选中文字后发送给 AI 进行修改
- 支持多种 AI 模型切换

### AI 动作

管理员可创建全局 AI 动作（如"润色"、"翻译"、"摘要"），用户也可创建个人动作。动作支持变量模板，可在不同上下文中复用。

## 实时协作

基于 y-websocket + Yjs CRDT 技术：

- **多人同时编辑** — 多人可同时编辑同一章节
- **光标同步** — 实时看到其他协作者的光标位置
- **在线状态** — 显示当前在线的协作者
- **分享管理** — 报告所有者可邀请其他用户协作

## 导出 DOCX

通过 report-engine 渲染引擎导出，支持：

- 富文本块完整导出（标题、列表、表格、公式、图片等）
- 条件段落渲染
- 子文档嵌套
- 自定义样式映射

## 附件管理

- 上传附件与报告关联
- 批量打包下载附件（ZIP 格式）
