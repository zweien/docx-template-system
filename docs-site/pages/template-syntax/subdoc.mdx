# 子文档 subdoc

子文档（subdoc）是 report-engine 的核心概念，用于在模板中嵌入动态生成的富文本内容。

## 基本语法

在 Word 模板中使用 `{{p PLACEHOLDER_SUBDOC }}` 标记子文档插入位置：

```
第一章 研究内容

{{p RESEARCH_CONTENT_SUBDOC }}

第二章 预算说明

{{p BUDGET_CONTENT_SUBDOC }}
```

## 与条件标志配对

子文档通常与条件标志配对使用：

```
{%p if ENABLE_RESEARCH %}
{{p RESEARCH_CONTENT_SUBDOC }}
{%p endif %}

{%p if ENABLE_BUDGET %}
{{p BUDGET_CONTENT_SUBDOC }}
{%p endif %}
```

## 命名规则

### 自动配对

report-engine 会自动配对条件标志和子文档：

- `ENABLE_RESEARCH` 配对 `RESEARCH_CONTENT_SUBDOC`
- `ENABLE_BUDGET` 配对 `BUDGET_CONTENT_SUBDOC`

规则：去掉 `ENABLE_` 前缀，加上 `_SUBDOC` 后缀。

### 中文命名

支持中文占位符名：

```
{{p 研究内容_SUBDOC }}
```

系统会自动识别中文字符并正确配对。

## Payload 结构

```json
{
  "sections": [
    {
      "id": "research",
      "placeholder": "RESEARCH_CONTENT_SUBDOC",
      "flag_name": "ENABLE_RESEARCH",
      "enabled": true,
      "blocks": [
        { "type": "heading", "text": "研究背景", "level": 2 },
        { "type": "paragraph", "text": "详细内容..." }
      ]
    }
  ]
}
```

每个 section 包含：

| 字段 | 说明 |
|------|------|
| `id` | 唯一标识 |
| `placeholder` | 子文档占位符名称 |
| `flag_name` | 对应的条件标志 |
| `enabled` | 是否启用 |
| `blocks` | 富文本块列表 |

## 附录子文档

特殊的 `APPENDICES_SUBDOC` 用于附录：

```json
{
  "attachments_bundle": {
    "placeholder": "APPENDICES_SUBDOC",
    "flag_name": "ENABLE_APPENDICES",
    "page_break_between_attachments": true,
    "include_attachment_title": true
  }
}
```

## 子文档标题

每个子文档可以设置标题：

```json
{
  "id": "research",
  "placeholder": "RESEARCH_CONTENT_SUBDOC",
  "subdoc_title": "研究内容",
  "subdoc_title_level": 2,
  "blocks": [...]
}
```

渲染时会在子文档内容前插入指定级别的标题。
