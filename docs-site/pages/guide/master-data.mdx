# 主数据管理

主数据管理模块提供灵活的数据表构建能力，支持多种字段类型、多种视图、公式引擎和公开分享。

## 数据表

### 创建数据表

1. 进入 **主数据** 页面
2. 点击 **新建数据表**
3. 设置数据表名称和描述
4. 添加和配置字段

### 15 种字段类型

| 类型 | 说明 |
|------|------|
| 文本 | 单行文本 |
| 数字 | 数值类型 |
| 日期 | 日期选择器 |
| 单选 | 彩色标签单选 |
| 多选 | 彩色标签多选 |
| 邮箱 | 邮箱格式验证 |
| 电话 | 电话号码 |
| 附件 | 文件上传 |
| URL | 链接地址 |
| 勾选框 | 布尔值 |
| 关联 | 关联其他数据表 |
| 关系子表格 | 嵌套子表格 |
| 自动编号 | 自增编号 |
| 创建/修改时间 | 自动记录时间 |
| 创建/修改人 | 自动记录操作人 |
| 公式 | 动态计算字段 |

## 五种视图

### 表格视图（Grid）

默认的表格视图，支持：

- 双击编辑单元格
- 批量填充和拖拽复制
- 撤销/重做（Ctrl+Z / Ctrl+Y）
- 查找替换（Ctrl+F）
- 多字段排序和条件筛选
- 条件格式（自动设置背景色/文字颜色）
- 列冻结
- 行高调整（紧凑/标准/宽松）
- 分组折叠

### 看板视图（Kanban）

按某个字段的值分组，以卡片形式展示记录。适合任务管理、状态追踪等场景。

### 画廊视图（Gallery）

以卡片画廊形式展示记录，突出展示图片和关键信息。

### 时间线视图（Timeline）

按日期字段展示记录的时间线，适合项目进度管理。

### 表单视图（Form）

将数据表配置为可填写的表单，支持：

- 拖拽排序字段
- 字段分组
- 自定义标题、描述和提交按钮文字

## 公式引擎

### 内置函数

共 26 个内置函数，覆盖数学、逻辑、文本、日期四大类别：

- **数学**：SUM, AVERAGE, MIN, MAX, ROUND, ABS, CEILING, FLOOR
- **逻辑**：IF, AND, OR, NOT
- **文本**：CONCAT, LEN, LEFT, RIGHT, MID, UPPER, LOWER, TRIM
- **日期**：NOW, YEAR, MONTH, DAY, DATE_DIFF
- **转换**：NUMBER, TEXT

### 公式编辑器

- 输入 `{` 触发字段引用补全
- 输入函数名触发函数自动补全
- 函数参考面板（语法 + 参数 + 示例）
- 实时预览计算结果
- 语法错误提示和循环引用检测

## 公开分享

### 分享链接

1. 创建表单视图或使用现有表单视图
2. 生成带过期时间的公开 URL
3. 分享给外部用户

### 公开表单

- 无需登录即可填写提交
- 字段类型安全校验
- 提交次数统计

## Excel 导入导出

- **导入**：从 Excel 导入数据，支持字段映射和去重
- **导出**：将记录数据导出为 Excel 文件

## 数据备份

- 完整导出/导入数据表结构（字段配置）
- 完整导出/导入数据记录
