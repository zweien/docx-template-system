# 简单占位符

在 Word 文档中使用 `{{ key }}` 标记需要替换的字段。系统会在文档生成时将占位符替换为表单中填写的数据。

## 基本用法

在 Word 文档中写入占位符：

```
合同编号：{{ contractNo }}
甲方名称：{{ partyA }}
签订日期：{{ signDate }}
```

填写表单后生成文档，占位符会被替换为实际值：

```
合同编号：HT-2026-001
甲方名称：XX科技有限公司
签订日期：2026年1月15日
```

## 命名规则

占位符 key 支持以下字符：

- **英文字母**：大小写均可
- **数字**：0-9
- **下划线**：`_`
- **中文字符**：支持中文命名

示例：

```
{{ 合同编号 }}
{{ partyName }}
{{ total_amount }}
{{ 签订日期 }}
```

## 字段类型

在模板配置页面，可以为每个占位符设置类型：

| 类型 | 说明 | 表单控件 |
|------|------|----------|
| 文本 | 单行文本 | 输入框 |
| 多行文本 | 多行文本 | 文本域 |

## 选项模板

支持单选和多选类型：

### 单选

```
{{选项:性别|single}}
□ 男
□ 女
```

### 多选

```
{{选项:适用范围|multiple}}
□ 选项1
□ 选项2
□ 选项3
```

### 内联勾选写法

```
{{选项:单项|single}}
单项：☑是 ☐否

{{选项:多选|multiple}}
多选：☐选项1 ☑选项2 ☑选项3 ☐选项4
```

## Word 兼容性

真实 Word 模板中，占位符文本可能被 Word 拆分为多个 XML run。例如 `{{ contractNo }}` 可能被拆成：

- `{{`
- ` contractNo`
- ` }}`

系统解析器会自动合并这些分散的 run，确保正确识别占位符。
